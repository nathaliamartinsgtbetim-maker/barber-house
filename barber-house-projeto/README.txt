BARBER HOUSE — SISTEMA DO SALÃO

1. Instale Node.js e MySQL 8.
2. Copie .env.example para .env e coloque a senha do MySQL.
3. No MySQL, execute schema.sql.
4. Na pasta do projeto: npm install
5. Execute: node seed.js
6. Execute: node server.js
7. Abra index.html por um servidor local (ex.: npx.cmd http-server -p 5500).

API: http://localhost:3000/api
